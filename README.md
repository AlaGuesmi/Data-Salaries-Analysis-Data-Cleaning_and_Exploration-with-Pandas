# 💼 Data-Salaries-Analysis-Data-Cleaning_and_Exploration-with-Pandas

This project explores and analyzes a dataset containing **salary information for data professionals across various roles, countries, and experience levels**. It demonstrates more advanced data preprocessing and exploratory data analysis (EDA) using Pandas and NumPy.

📂 **Dataset Overview**

The dataset includes salary records for data-related roles from 2020 onward. Key fields include:

- job_title – e.g., Data Scientist, Data Engineer, ML Engineer

- experience_level – Junior to Senior (EN, MI, SE, EX)

- salary_in_usd – standardized salary value

- company_location and company_size – geographic and organizational context

🔍 **Project Objectives**

- Understanding the Dataset

- Initial exploration with .head(), .tail(), info(), and describe()

- Identifying key variables like job_title, salary, experience_level, and company_location

- Handling Missing Data

- Detection of null or missing values

- Imputation using:

   Mean for numerical columns

   Mode or most/least frequent values for categorical columns

 - Data Exploration & Insights:

   Grouping and aggregation using groupby()

   Frequency analysis with value_counts()

- Identifying dominant roles and company patterns

- Comparative insights across job titles, experience levels, and company sizes

🧰 **Tools & Libraries**

- Python

- Pandas

- NumPy

*This project helps illustrate how data quality impacts analysis and how thoughtful preprocessing can drive meaningful insights from real-world salary data.*
